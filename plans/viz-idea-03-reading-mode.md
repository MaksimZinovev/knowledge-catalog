# Idea 3 (aspirational) — Reading mode instead of detail pane

Kill the 40% side pane. Selecting a node opens a clean full-width "card" overlay: title, type chip, badges, then the body rendered as collapsible sections (H2s become accordion headers, all collapsed beyond the first). Internal links become footnote-style chips at the end of each section + a "related / backlinks" rail. Deep-linkable via URL hash (`viz.html#node-id`) so cards can be shared/bookmarked, and back/forward works.

Rationale: the biggest rework but makes the viz double as an actual wiki reader — the graph becomes navigation, not the destination. Possible variant: split "graph / read" toggle.
